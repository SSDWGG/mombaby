沐奶时光

母婴喂奶记录 App

iOS 原生体验 · 本地数据 · 无广告

核心功能

一切围绕新生儿喂养场景设计，简单、清晰、贴心

🍼

喂奶记录

记录每天每次喂奶的时间和奶量，自动汇总总奶量、次数和平均奶量。

🔔

定点提醒

设定每日固定时间提醒，包含建议奶量，可同步写入 iOS 系统提醒事项。

⏱

倒计时喂奶

单次倒计时模式，灵活应对不规律的喂奶间隔，到点自动提醒。

📊

时间线视图

按天浏览喂奶历史记录，直观查看喂养规律和趋势变化。

📖

月龄参考指南

0-30 月龄身高体重参考、喂养奶量建议、行为表现和养育经验。

🔒

隐私优先

所有数据存储在手机本地，无需网络权限，不上传任何个人信息。

安装方式

目前仅支持通过 Xcode 侧载安装到 iPhone

📲 通过 Xcode 安装

  1. 克隆仓库到 Mac
  2. 运行 npm run ios 打开 Xcode 工程
  3. 在 Signing & Capabilities 中选择个人开发团队
  4. 连接 iPhone 后点击 Run
